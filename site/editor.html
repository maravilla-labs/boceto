Boceto editor

A canvas editor for hand-drawn wireframes — drag, resize, multi-select, undo. Built directly on top of <boceto-edit>.

Coming soon

The interactive editor lands in a future release. The data model and component contract are already stable; the next step is wiring up canvas interactions onto the renderer that ships today.

In the meantime, author wireframes by typing the DSL directly into a markdown file or a fenced code block and using <boceto-view> to render.

What it'll look like

This is a static preview of the planned editor chrome — toolbar on the left, canvas in the middle, properties panel on the right.

Stable API now

Even though interactions aren't shipping yet, the <boceto-edit> component already exposes the API surface the editor will use:

<boceto-edit
  code='element box 0 0 100 50 "Hello"'
  width="600"
  height="400"
></boceto-edit>

// Listen for changes
document.querySelector('boceto-edit')
  .addEventListener('change', (e) => console.log(e.detail.code))

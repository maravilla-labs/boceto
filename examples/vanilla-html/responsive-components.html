Responsive components

One Panel definition — three placements, all adapting automatically.

← back to main showcase

A flex-shell component declares its layout on the component header line. The body becomes flex children of an implicit shell sized to the resolved instance box — so the same component adapts to fit whatever container holds it.

1 · Fixed call-site size

The simplest case: drop the panel at an explicit W × H. The body flows according to the panel's direction=col padding=12 gap=8.

Show source 
component Panel(title) direction=col align=stretch padding=12 gap=8 w=300 h=auto min-w=200 max-w=600
  element heading 0 0 0 24 "$title"
  element box 0 0 0 0 "" grow=1
end

element Panel 80 40 400 160 "" title="Stats"

2 · Inside a row with grow=1

Same Panel definition, but now it sits in a row next to a fixed-width box. grow=1 on the panel + align=stretch on the row makes it fill both the remaining horizontal space and the row's full height. The body re-flows against the new size.

Show source 
row 40 40 700 160 gap=12 align=stretch
  element box 0 0 200 0 "Sidebar"
  element Panel 0 0 auto auto "" grow=1 title="Main"
end

3 · Wrap-row grid

row wrap=wrap + min-w on each panel gives you a responsive grid. The panels pack as many as fit on a line, then flow onto the next. No grid backend needed — flexbox with wrapping covers the wireframe case.

Show source 
row 20 20 720 320 gap=12 wrap=wrap align=start
  element Panel 0 0 auto auto "" title="One"
  element Panel 0 0 auto auto "" title="Two"
  element Panel 0 0 auto auto "" title="Three"
  element Panel 0 0 auto auto "" title="Four"
  element Panel 0 0 auto auto "" title="Five"
  element Panel 0 0 auto auto "" title="Six"
end

4 · Absolute-body component (no shell)

Components without a direction= attribute keep the v0.1 absolute-body model — body coordinates are relative to the instance origin, and the body does not re-flow when the instance is resized. Useful for pixel-precise widgets.

Show source 
component UserCard(name, role)
  element card 0 0 240 80 ""
  element avatar 8 8 40 40 ""
  element heading 56 12 180 24 "$name"
  element label 56 38 180 18 "$role"
end

element UserCard 40 40 240 80 "" name="Jane Doe" role="Admin"
element UserCard 40 140 240 80 "" name="John" role="User"

5 · App shell: fixed-height chrome, flexible main

The classic three-row app shell. Header and Footer have fixed heights declared on the component (h=56 / h=44); Main uses grow=1 to fill whatever's left. Resize AppShell's call-site H and the main area grows or shrinks while the chrome stays the same height.

Show source 
component Header(title) direction=row align=middle padding=16 gap=8 h=56
  element heading 0 0 0 28 "$title" grow=1
  element button 0 0 80 32 "Action"
end

component Footer() direction=row align=middle padding=16 h=44
  element label 0 0 0 16 "© 2026" grow=1
  element label 0 0 200 16 "v1.0.0"
end

component Main() direction=col align=stretch padding=16 gap=12 grow=1
  element heading 0 0 0 24 "Welcome"
  element box 0 0 0 0 "" grow=1
end

component AppShell(title) direction=col align=stretch
  element Header 0 0 0 0 "" title="$title"
  element Main 0 0 0 0 ""
  element Footer 0 0 0 0 ""
end

element AppShell 20 20 720 460 "" title="My App"

6 · Dynamic chrome height (sized by content)

The header has h=auto — it sizes itself to the tallest child inside it (here, a button at h=40 plus padding=12 on each edge = 64). Add more buttons or taller content and the header expands automatically.

Show source 
component DynHeader(title) direction=row align=middle padding=16 gap=8 h=auto
  element heading 0 0 0 32 "$title" grow=1
  element button 0 0 100 40 "Save"
  element button 0 0 100 40 "Cancel"
end

component DynMain() direction=col align=stretch padding=16 gap=12 grow=1
  element heading 0 0 0 24 "Content area"
  element box 0 0 0 0 "" grow=1
end

component DynShell(title) direction=col align=stretch
  element DynHeader 0 0 0 0 "" title="$title"
  element DynMain 0 0 0 0 ""
end

element DynShell 20 20 720 340 "" title="Header sizes to content"

7 · Sidebar + main, two-column pattern

A horizontal split: Sidebar is fixed at w=200, Main grows to fill. Swap the sidebar's w to w=auto and add content with explicit widths to see it size to its content instead.

Show source 
component Sidebar() direction=col align=stretch padding=16 gap=8 w=200
  element heading 0 0 0 20 "Menu"
  element button 0 0 0 32 "Home"
  element button 0 0 0 32 "Settings"
  element button 0 0 0 32 "Profile"
end

component Main() direction=col align=stretch padding=16 gap=8 grow=1
  element heading 0 0 0 24 "Dashboard"
  element box 0 0 0 0 "" grow=1
end

component TwoCol() direction=row align=stretch
  element Sidebar 0 0 0 0 ""
  element Main 0 0 0 0 ""
end

element TwoCol 20 20 720 280 ""

8 · Modal: built-in element with block-form children

The modal element type IS the chrome — no composite needed. A trailing : opens a children block; the chrome's intrinsic 40px header inset keeps the body below the title bar automatically. h=auto + direction=col grows the modal to fit its content.

Show source 
element box 0 0 780 360 "" id=backdrop
element modal 190 60 400 auto "Confirm action" direction=col padding=16 gap=12 align=stretch :
  element label 0 0 0 18 "Are you sure you want to continue?"
  element input 0 0 0 36 "Reason (optional)"
  row 0 0 0 36 gap=8 justify=end
    element button 0 0 100 32 "Cancel"
    element primary-button 0 0 100 32 "Confirm"
  end
end

9 · Min/max as responsive guardrails

Same Panel placed in two rows of different widths. min-w=180 prevents the panels from getting too narrow when the row wraps; max-w=280 stops them from ballooning when there's extra space. Resize your browser to see how the constraints hold.

Show source 
component Card(label) direction=col align=stretch padding=10 gap=6 h=auto min-w=180 max-w=280
  element heading 0 0 0 20 "$label"
  element label 0 0 0 16 "Subtitle"
  element box 0 0 0 60 ""
end

row 20 20 720 180 gap=12 wrap=wrap align=start
  element Card 0 0 auto auto "" label="One" grow=1
  element Card 0 0 auto auto "" label="Two" grow=1
  element Card 0 0 auto auto "" label="Three" grow=1
end

row 20 220 380 180 gap=12 wrap=wrap align=start
  element Card 0 0 auto auto "" label="A" grow=1
  element Card 0 0 auto auto "" label="B" grow=1
  element Card 0 0 auto auto "" label="C" grow=1
end

10 · Composition: panel containing a card

Composites nest freely: a flex-shell panel can contain an absolute-body card, and the card's reference appears inside the panel's body just like any other element.

Show source 
component UserCard(name)
  element card 0 0 200 60 ""
  element heading 8 8 180 20 "$name"
  element label 8 32 180 16 "Member"
end

component Panel(title) direction=col align=stretch padding=8 gap=8
  element heading 0 0 0 24 "$title"
  element UserCard 0 0 0 60 "" name="Alice"
  element UserCard 0 0 0 60 "" name="Bob"
end

element Panel 40 40 320 220 "" title="Team"

11 · Built-in element as flex container

Any built-in element type accepts block-form children via a trailing :. The element's chrome (border, header, etc.) renders normally; children render inside the content rect. With direction= the children flow as flex; without it, they keep their declared local (x, y).

Show source 
# Flex mode: direction=col, children flow with gap/padding
element box 20 20 360 auto "" direction=col padding=12 gap=8 align=stretch :
  element heading 0 0 0 24 "In a box"
  element label 0 0 0 18 "Flex container"
  row 0 0 0 36 gap=8 justify=end
    element button 0 0 80 28 "Cancel"
    element primary-button 0 0 80 28 "OK"
  end
end

# Absolute body: children at declared local (x, y), no flex flow
element box 420 20 340 auto "" :
  element heading 12 12 0 24 "Overlay"
  element label 12 48 0 18 "Absolute body"
  element button 12 80 100 32 "At (12, 80)"
  element label 12 124 0 16 "Manual coords"
end

12 · Chrome elements with intrinsic insets

Element types that draw a header bar — card, modal, window-frame, browser-frame — automatically push children below the chrome. You don't write padding-top=40 manually; the layout pass adds the inset for you.

Show source 
element card 20 20 220 auto "" direction=col padding=12 gap=8 align=stretch :
  element label 0 0 0 16 "Card content"
  element label 0 0 0 16 "below the divider"
end

element modal 260 20 260 auto "Modal" direction=col padding=12 gap=8 align=stretch :
  element label 0 0 0 16 "Body sits below"
  element label 0 0 0 16 "the title bar"
  row 0 0 0 32 gap=6 justify=end
    element button 0 0 70 28 "OK"
  end
end

element window-frame 540 20 220 auto "" direction=col padding=12 gap=8 align=stretch :
  element label 0 0 0 16 "macOS-style"
  element label 0 0 0 16 "titlebar"
end

element browser-frame 20 220 740 160 "" direction=col padding=12 gap=8 align=stretch :
  element label 0 0 0 16 "Tabs + URL bar"
  element label 0 0 0 16 "automatically inset"
end

13 · Generic border and shadow

Any element accepts border=true|N|#color and shadow=true|N as optional decoration. Use them to give a plain element extra visual weight, or to make a card feel "floating" with a drop shadow — independent of the element type's natural chrome.

Show source 
element box 20 30 220 140 "Plain"
element box 270 30 220 140 "Blue border" border=#3b82c4
element box 520 30 220 140 "Shadow + border" border=true shadow=14
